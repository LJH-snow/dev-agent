# Multi-Agent Collaborative Execution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade `:team` from read-only specialist planning to isolated, observable, review-before-merge collaborative execution.

**Architecture:** Agent Core will expose a provider-neutral DAG executor that runs `AgentLoop` tasks through an injected workspace provider. The CLI will provide a Git worktree provider, project the task lifecycle into the Ink store, and merge only after an explicit `:team apply` command.

**Tech Stack:** TypeScript, Node.js `node:test`, `@dev-agent/agent-core`, `@dev-agent/executor`, Git worktrees, Ink 6, React 19.

**Spec:** `docs/superpowers/specs/2026-09-22-multi-agent-execution-design.md`

**Status:** complete

## Global Constraints

- No task may write to the current working directory before `:team apply`.
- Every task workspace must be generated by the workspace provider.
- Missing dependencies and cycles fail before any workspace is created.
- Failed tasks are retried independently; unrelated tasks keep running.
- A merge conflict is reported and never force-applied.
- Existing `runCollaborativePlan`, normal runs, `:plan`, and `:apply` contracts stay compatible.

```ts
export interface CollaborationWorkspaceProvider {
  create(task: CollaborationTask, options: { signal: AbortSignal }): Promise<CollaborationWorkspace>;
  inspect(workspace: CollaborationWorkspace, options: { signal: AbortSignal }): Promise<CollaborationDiff>;
  dispose(workspace: CollaborationWorkspace): Promise<void>;
  merge?(review: CollaborationReview, options: { signal: AbortSignal }): Promise<CollaborationMergeResult>;
}

export interface CollaborativeExecutionOptions {
  readonly model: ModelProvider;
  readonly tools?: ToolCollection;
  readonly tasks: readonly CollaborationTask[];
  readonly workspaceProvider: CollaborationWorkspaceProvider;
  readonly workingDirectory: string;
  readonly sessionId: string;
  readonly maxParallel?: number;
  readonly maxTurns?: number;
  readonly retryLimit?: number;
  readonly signal?: AbortSignal;
  readonly createMemory?: (task: CollaborationTask) => AgentMemory;
  readonly approval?: ApprovalPolicy;
  readonly onEvent?: (event: CollaborationExecutionEvent) => void;
}
```
