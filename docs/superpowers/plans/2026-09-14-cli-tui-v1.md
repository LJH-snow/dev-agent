# CLI Modern TUI v1 Implementation Plan

> **For agentic workers:** Use task-by-task execution with TDD. This plan preserves the line-oriented and JSON paths while adding a TTY-only presentation layer.

**Goal:** 将 CLI 交互模式升级为有欢迎屏、状态栏、命令提示、可读回答和轻量 Markdown 的现代终端界面。

**Architecture:** 新增无副作用的终端渲染模块；`index.ts` 只负责判断是否处于真实 TTY、把已有 agent callbacks 接到渲染器，并在非 TTY/脚本模式保留旧路径。渲染器不持有模型或工具状态，不改变 agent loop。

**Tech Stack:** TypeScript、Node.js readline、ANSI escape sequences、现有 CLI test runner。

**Spec:** `docs/cli-tui-v1.md`

## Global Constraints

- `--json`、`--once`、`--mcp-server` 和非 TTY 调用不得出现 TUI 控制字符。
- 不新增运行时依赖，不修改 provider、tool、approval、validation、MCP 或 session schema。
- 所有新增视觉行为先有 RED test，再实现 GREEN。
- `NO_COLOR` 保持纯文本可读；窄终端不生成超过声明宽度的边框行。
