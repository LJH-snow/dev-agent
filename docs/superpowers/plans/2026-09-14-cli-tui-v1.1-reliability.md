# CLI Modern TUI v1.1 Reliability Implementation Plan

> This plan tightens the existing TTY-only presentation without changing the agent loop or
> machine-readable paths.

**Goal:** 修复 TUI v1 的真实终端输入重复、首 token 等待无反馈和高频流式重绘问题。

**Spec:** `docs/cli-tui-v1.1-reliability.md`

## Global constraints

- rich UI 只存在于真实 TTY；`--json`、`--once`、`--mcp-server`、pipe/CI 保持旧输出。
- 不增加 runtime dependency，不修改 provider/tool/approval/validation/MCP/session schema。
- 生产代码变更必须先有失败测试，再实现通过。
- 不创建 release tag 或 GitHub Release。

## Task 1: Streaming renderer reliability

**Files:**
- Modify: `apps/cli/src/tui-stream.ts`
- Test: `apps/cli/tests/tui-stream.test.ts`

- [x] Add deterministic render throttling with an injectable clock or equivalent test seam.
- [x] Ensure `finish()` flushes the latest buffered text and leaves a stable final block.
- [x] Add regression coverage for incomplete fenced code visibility and complete final content.

## Task 2: Rich input and waiting lifecycle

**Files:**
- Modify: `apps/cli/src/index.ts`
- Test: `apps/cli/tests/interactive.test.ts`

- [x] Avoid printing the readline-echoed user input a second time in rich mode.

- [x] Preserve `:help`, `:clear`, `:model`, `:quit`, `:validate`, `:cleanup`, `exit`, `quit`, EOF,
  approval and abort behavior.
